## How to open the website

1. Open this folder in Visual Studio Code.
2. Put the required images into the `images` folder.
3. Put the resume PDF into the `resume` folder.
4. Open `index.html` in a browser.
5. For easier development, use the VS Code Live Server extension if installed.

## GitHub

The GitHub profile URL is intentionally left blank in `script.js`.

After getting the GitHub profile URL, open `script.js` and replace:

`const githubUrl = "";`

with:

`const githubUrl = "https://github.com/yourusername";`
